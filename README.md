# Train de vie

Web app de suivi des charges fixes et des dépenses, 100 % locale : aucun compte, aucun serveur, aucun appel réseau. Les données restent dans le navigateur (`localStorage`).

## Lancer
Ouvrir `index.html` dans un navigateur. Pour essayer sans vraies données : écran « Postes » › « Essayer avec de faux chiffres ».

## Fonctions (V1)
- Postes à cocher, postes perso, budgets proposés d'après le mois précédent
- Camembert par catégorie, tuiles compactes, dépassement de budget signalé
- Simulateur « Et si ? »
- Mode démo (12 mois de faux chiffres, rangés à part)
- Import des paiements Apple Pay via un fichier relais rempli par un raccourci iPhone

⚠️ Safari peut effacer les données d'un site peu utilisé : pas de vraies données tant qu'il n'y a pas de sauvegarde.
